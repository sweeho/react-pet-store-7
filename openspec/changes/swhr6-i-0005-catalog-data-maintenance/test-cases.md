#### SWHR6-R-0002.01 · Initial load on an empty store
- **SWHR6-C-0175** (integration, approved, v1) Initial load seeds users, customers, categories and locale details
  - Preconditions: A fresh database with migrations applied and no rows in users, customers, categories or category details tables.
  - Step 1: Run the initial load (seed) against the empty store.
  - Step 2: Query the users table and count rows.
  - Step 3: Query the customers table and match each to a user.
  - Step 4: Query the categories table and count rows.
  - Step 5: For each category, query its details and list the distinct locales.
  - Expected: Four users exist, each with a matching customer; five categories exist, each with details in exactly three locales (15 detail rows in total).
- **SWHR6-C-0176** (e2e, approved, v1) Initial load run via the app entry point on a new install
  - Preconditions: No sqlite.db file exists; the app is started clean.
  - Step 1: Start the app so the initial load runs on the empty store.
  - Step 2: Open the catalog in the UI or call the catalog API for each of the three locales.
  - Expected: The catalog shows five categories in each of the three locales, and the four seeded users with their customers are retrievable.
