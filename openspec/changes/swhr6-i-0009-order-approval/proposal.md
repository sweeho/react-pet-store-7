## Why

Recover the order-approval behaviour of the legacy pet store order processing centre so it can be rebuilt: which orders are approved automatically, how administrators approve or deny the rest, and what happens to each decision.

## What Changes

- Specify automatic approval limits by locale, the initial PENDING state, the batch approval-decision flow, the PENDING-only guard, the allowed order status values and the approval document shape.
- One approved requirement (SWHR6-R-0011, batch decisions) and several draft requirements awaiting SME decision.

## Impact

- Capability: order-approval. No screen records were extracted for it.
